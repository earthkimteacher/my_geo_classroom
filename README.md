## 슬라이드 사용법

설치할 것 없이 주소만 열면 됩니다. 화면 크기에 맞춰 자동으로 커지고 작아집니다.

| 키 | 기능 |
|---|---|
| → / Space / 클릭 | 다음 (애니메이션 중이면 그 애니메이션을 바로 끝냄) |
| ← | 이전 |
| O | 목차 — 모든 장이 썸네일로 펼쳐지고, 누르면 그 장으로 이동 |
| N | 발표자 노트 |
| L | 레이저 포인터 — 누른 채 움직이면 선이 그려졌다가 사라짐 |
| M | 책갈피·메모 — 지금 위치를 저장해 두고 다음에 이어 보기 |
| B / W | 검은 화면 / 흰 화면 |
| F | 전체 화면 |
| ? | 도움말 |
| Esc | 열린 창 닫기, 레이저 끄기 |

화면 오른쪽 아래에 마우스를 가져가면 같은 기능의 버튼이 나타납니다.

### 주소 옵션
주소 끝에 붙여서 씁니다. 여러 개는 `&`로 잇습니다.

| 옵션 | 기능 | 예시 |
|---|---|---|
| `?s=1` | 학생 모드 (발표자 노트 숨김) | 학생에게 링크를 나눠 줄 때 |
| `?ans=0` | 빈칸 정답·문제 풀이 숨김 | 학생용 학습지 인쇄 |
| `?print=1` | 인쇄 모드 (모든 장을 흰 배경으로) | 레이저 프린터 인쇄 |
| `?still=1` | 정지 화면 (컨트롤 숨김, 애니메이션 없이 최종 상태) | 캡처·PDF 만들기 |
| `#6` | 6번째 장부터 열기 | |
| `&k=2` | 그 장의 2단계 상태로 열기 | |

예) 학생용 인쇄: `https://earth.esbest.net/지구시스템과학/II.05tide.html?s=1&ans=0&print=1`

## 폴더 구조
```
my_geo_classroom/
├─ 과학탐구실험2/
│  └─ I.06environment.html            학교 주변 환경 탐구 슬라이드
├─ 지구과학/
│  ├─ 행성의 역행과 순행 시뮬레이터.html
│  └─ 밀란코비치 시뮬레이터.html
├─ 지구시스템과학/
│  ├─ II.05tide.html                  조석 슬라이드
│  └─ PDF/
│     └─ II.05tide_학생용.pdf          조석 학생용 인쇄본
├─ index.html                         사이트 첫 화면 (수업 자료 목록)
├─ CLAUDE.md                          슬라이드 제작 안내 (Claude용)
└─ CNAME                              earth.esbest.net 연결
```

- 파일 이름 규칙: 과목 폴더 안에 `단원번호+영어 주제.html` (예: `지구시스템과학/II.05tide.html`). 학생용 PDF는 과목 폴더의 `PDF/` 안에 `같은이름_학생용.pdf`
- 브라우저 탭 제목 규칙: `과목명 - 단원 번호. 단원명 - 진광고등학교 교사 김덕영`

## 만드는 방식
- 각 슬라이드는 **파일 하나로 완결된 HTML**입니다. 외부 라이브러리 없이 동작하며, 글꼴(Pretendard)만 인터넷에서 불러옵니다.
- 그래프·힘 화살표·궤도 같은 그림은 실제 식으로 계산해 그리고, 클릭할 때마다 단계별로 나타나도록 만듭니다.
- 슬라이드는 Claude와 함께 만듭니다. 제작 규칙, 수업 자료 스타일, 엔진 구조는 [CLAUDE.md](CLAUDE.md)에 정리되어 있습니다.
- `main` 브랜치에 올리면 몇 분 뒤 https://earth.esbest.net 에 자동으로 반영됩니다.

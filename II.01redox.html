산화·환원 반응식

원자 수만 맞추면 될까?

화학 반응식: 원자의 종류와 수가 같도록 계수를 맞춘다
산화·환원 반응식: 원자 수 + 주고받는 전자 수도 같아야 한다

Sn2++ 2Fe3+→ Sn4++ 2Fe2+

반쪽 반응

산화·환원 반응을 산화 반응과 환원 반응으로 나누어 나타낸 것

산화Sn2+ → Sn4+ + 2e−
환원Fe3+ + e− → Fe2+ (×2)

Sn·Fe 반응은 이해를 돕기 위한 예(교과서 밖)
반쪽 반응식

반쪽 반응식으로 완성하는 5단계

MnO4−(aq) + Sn2+(aq) + H+(aq) → Mn2+(aq) + Sn4+(aq) + H2O(l)
1단계
산화 반응과 환원 반응으로 나눈다
산화Sn2+ → Sn4+환원MnO4− → Mn2+
2단계
원자 수 맞추기: O·H가 아닌 원자 먼저 → H2O로 O → H+로 H
Sn2+ → Sn4+MnO4− + 8H+ → Mn2+ + 4H2O
3단계
화살표 양쪽의 전하량이 같도록 전자를 더한다
Sn2+ → Sn4+ + 2e−MnO4− + 8H+ + 5e− → Mn2+ + 4H2O
4단계
잃은 전자 수 = 얻은 전자 수가 되도록 곱한다 (×5, ×2)
5Sn2+ → 5Sn4+ + 10e−2MnO4− + 16H+ + 10e− → 2Mn2+ + 8H2O
5단계
두 반쪽 반응식을 더한다 (양쪽의 10e−는 지워진다)
2MnO4− + 5Sn2+ + 16H+ → 2Mn2+ + 5Sn4+ + 8H2O
확인: 반응물 총 전하 (−1)×2 + (+2)×5 + (+1)×16 = +24  =  생성물 (+2)×2 + (+4)×5 = +24 ✓

맞을까, 틀릴까?

“산화제는 산화되는 물질이다.”
✕
산화제는 다른 물질을 산화시키고, 자신은 환원된다
예: Fe2O3 + 3CO → 2Fe + 3CO2의 Fe2O3
“산화수는 원자가 실제로 띠는 전하이다.”
✕
공유 전자쌍이 모두 옮겨 갔다고 가정한 가상적인 전하
예: H2O의 O는 −2이지만 실제 −2 전하는 없다
“화합물에서 O의 산화수는 항상 −2이다.”
✕
과산화물에서는 −1, 플루오린 화합물에서는 +1 또는 +2
예: H2O2(−1), OF2(+2)
“모든 화학 반응은 산화·환원 반응이다.”
✕
산화수가 변하는 원자가 있어야 산화·환원 반응
예: HCl + NaOH → H2O + NaCl은 변화 없음
